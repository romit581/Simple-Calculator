### 🧮 Simple Calculator (Java)

This is a **Simple Calculator** application built using **Java**. It performs basic arithmetic operations such as **addition, subtraction, multiplication, and division**. The project is designed with a **user-friendly interface** and helps beginners understand **Java GUI programming** and **event handling** concepts.

#### 🔧 Features

* Perform basic operations: `+`, `-`, `×`, `÷`
* Clear and reset functionality
* Handles invalid inputs gracefully
* Built using **Java Swing / AWT** (if you used them)
* Simple, easy-to-understand code structure

#### 💡 Technologies Used

* **Java (JDK 8 or above)**
* **Swing / AWT** for GUI
* **NetBeans / Eclipse / IntelliJ IDEA** (optional, mention if you used one)

#### 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/romit581/SimpleCalculator.git
   ```
2. Open the project in your preferred Java IDE.
3. Compile and run the `Calculator.java` file.

#### 📚 Learning Outcomes

* Understanding of **Java GUI components**
* Implementation of **ActionListener** for button clicks
* Practice in **object-oriented programming (OOP)** principles
